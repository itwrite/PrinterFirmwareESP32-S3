## B. 喷头（Phase 7 前必须闭合；未闭合前只有 MockPrintheadHal）

| # | 问题 | 为什么必须知道 |
|---|---|---|
| Q10 | 品牌、型号、官方资料（Datasheet/Programming Manual）链接或文件 | 一切驱动时序的唯一依据 |
| Q11 | 电气接口类型与驱动板/驱动芯片？（并口/串行 SPI？自带驱动板还是裸喷头？） | 决定用 GPIO/RMT/LCD_CAM/SPI 哪条路径 |

| Q15 | 物理分辨率 dpi 与最大打印宽度？ | 校验 bytes_per_row 合法范围 |
| Q16 | 温度传感与点火温度窗口？过温策略？ | 保护与安全停机 |
| Q17 | 维护动作要求（清洗/盖帽/预喷）？ | FINALIZING 阶段动作 |
| Q18 | 是否有原厂参考代码/评估板资料可对照？ | 降低时序实现风险 |
